# LeetCode CMDK

### Press Cmd/Ctrl + K to search and insert Java & C++ syntax snippets directly into the editor.

[![Download Zip](https://custom-icon-badges.demolab.com/badge/-Download_Zip-black?style=for-the-badge&logo=download&logoColor=white)](https://github.com/Visalan-H/Leetcode-CmdK/archive/refs/heads/main.zip)

</div>

## Features

- **Search**: Press `Cmd+K` or `Ctrl+K`.
- **Code**: Get Java & C++ code fast.
- **Clean**: Minimal UI.

## How to Install

1. [Download this](https://github.com/Visalan-H/Leetcode-CmdK/archive/refs/heads/main.zip) and unzip it.
2. Go to `chrome://extensions` in your browser.
3. Turn on **Developer mode** (top right).
4. Click **Load unpacked**.
5. Pick the folder you unzipped.
